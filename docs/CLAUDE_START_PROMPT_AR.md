# نص بدء التنفيذ

نص المهمة الرئيسي الذي يُسلّم إلى Claude Code

النص التالي صياغة جاهزة لبدء التنفيذ، ويُرفق معه النص الكامل للمواصفات والحزمة المساندة. يقرأه Claude كتكليف عمل متدرج، لا كطلب ملخص. إذا كانت المحادثة السحابية لا تقرأ PDF كاملًا جيدًا، يكون ملف Markdown داخل الحزمة المرجع النصي المطابق، وتُحفظ روابط الفصول ومعرفات القبول في المستودع.

> أنت مسؤول تنفيذ تطبيق HadCtrl أصلي للآيفون باستخدام SwiftUI وSupabase داخل مستودع GitHub الذي أحدده. اقرأ هذه المواصفات كاملة قبل كتابة الكود، وحوّلها إلى مصفوفة متطلبات واختبارات مرتبطة بالمعرفات. المطلوب تطبيق عملي للمدير ورؤساء الأقسام، مع داشبورد شامل، وتنقل أصلي مبتكر، ومستهدفات ومؤشرات وتقارير ومهام ومنجزات ومرفقات وصلاحيات خادمية وسجل تدقيق. طبّق التفاصيل ومعالجة الحالات الاستثنائية الواردة في الوثيقة، ولا تستبدلها بنموذج بيانات ثابت أو WebView.
>
> افحص المستودع والأدوات المتاحة أولًا، واحتفظ بالعمل الموجود. اعتمد اسم المشروع والـ Scheme HadCtrl، واجعل العربية وRTL وتجربة الآيفون والإتاحة جزءًا من التصميم منذ البداية. ثبّت نسخ Xcode وSwift Package dependencies التي تحققت منها، واستخدم المهارات الموصى بها ضمن نطاقها، وسجل مصدرها وإصدارها. لا تثق باسم مهارة دون وجودها أو قراءتها، ولا تسمح لتوصية عامة بتجاوز قيود الصلاحيات أو متطلبات المنتج.
>
> ابدأ بهيكل قابل للبناء ثم نفذ الشرائح الوظيفية وبواباتها بالتسلسل. أنشئ migrations وRLS وRPC واختبارات قاعدة البيانات قبل إعلان نجاح الربط. لا تنقل service_role أو مفاتيح Apple أو مفاتيح APNs الخاصة إلى التطبيق. لا تنفذ reset أو تغييرات مدمرة على مشروع حي. أكمل ما يمكن إنجازه أثناء نقص المدخلات، واجمع الموانع الحقيقية مثل Bundle ID وأصول التوقيع ومرجع مشروع Supabase في قائمة محددة بدل اختلاقها أو تعطيل كل العمل بسببها.
>
> المطلوب النهائي مستودع كامل ونتائج CI حقيقية وArchive لجهاز حقيقي وIPA موقّع ومتحقق منه عند توافر إعدادات Apple. إذا لم تتوافر، سلّم المشروع القابل للبناء وما اختُبر وقائمة المتطلبات الناقصة بوضوح؛ لا تُسم ملف محاكي أو IPA غير موقع قابلًا للتثبيت. اكتب TEST_REPORT وBUILD_REPORT وSETUP وRUNBOOK ومصفوفة التتبع، مع الأوامر والنتائج وحدود التحقق، ودليل تنزيل IPA وتثبيته بالطريقة المتوافقة مع توقيعه.
>
> لا تعتبر المهمة منجزة لأن الشاشات جميلة. أثبت تدفق مدير يسند مهمة ورئيس قسم يرفع إنجازًا ومدير يعتمد، وتدفق تقرير يعاد ثم يعتمد، وحساب مؤشر يصحح دون محو نسخته. اجتز حالات الصفر والبيانات الناقصة والتأخر وتبديل الفترات والتزامن والصلاحيات وRTL وVoiceOver. عالج الإخفاقات الفعلية، ولا تعطل فحصًا أو تخفف سياسة للوصول إلى نتيجة خضراء. استمر حتى تتوافر نتيجة قابلة للمراجعة، ثم أبلغني بالمنجز والأدلة وما يحتاج إعدادًا خارجيًا فقط.
