| `Logo/Hadithah_Logo.svg` | Alhadithah General Hospital lockup (AlJouf Health Cluster emblem), vector, text as paths |

Per spec §05, external fonts ship in the app only when a valid license for app embedding is confirmed
and tests show they keep RTL and Dynamic Type working. Until that is confirmed, the app uses the system font.
The hospital logo is used as the official identity; the app icon remains a separate abstract mark (§05).
